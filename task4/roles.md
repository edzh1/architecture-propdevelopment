# Task 4 — Таблица ролей доступа в Kubernetes

| Роль | Права роли | Группы пользователей |
|-------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------|
| cluster-viewer    | Просмотр всех ресурсов в кластере (без возможности модификации и без доступа к Secret, ConfigMap, PersistentVolume)                                     | Бизнес-аналитики, тестировщики, product-менеджеры           |
| namespace-admin   | Полное управление ресурсами (Deployment, Service, Ingress, ConfigMap, Secret) **в рамках одного namespace**                                             | Разработчики фронтенда и бэкенда                            |
| cluster-ops       | Полный доступ ко всем ресурсам во всех namespace, включая чтение/запись Secret, Volume, CRD, RBAC-объекты                                               | DevOps-инженеры, инженер ИБ                                 |
| tenant-support    | Чтение ресурсов в namespace `tenant-services`, перезапуск подов и просмотр логов                                                                       | Служба поддержки жильцов                                    |
| smartaccess-admin | Установка и управление приложениями в namespace `smart-access`, включая настройки доступа к внешним API и настройку serviceAccount и network policies | Специалисты по партнёрским интеграциям (SmartAccess DevOps) |
