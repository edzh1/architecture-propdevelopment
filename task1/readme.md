# Анализ угроз информационной безопасности

## Категории угроз

### 1. Несанкционированное раскрытие информации
**Описание**: Компрометация конфиденциальных данных путем их незаконного получения или распространения.

**Потенциальный ущерб**: 
- Административные санкции согласно 152-ФЗ
- Подрыв деловой репутации
- Использование данных клиентов в мошеннических схемах
- Раскрытие коммерческой информации о финансовых возможностях организации
- Ущерб от промышленного шпионажа

### 2. Уничтожение информации
**Описание**: Безвозвратная утрата критически важных данных.

**Потенциальный ущерб**:
- Удаление информации о недвижимых активах (БД client-mart, client-tour)
- Отказ систем хранения (сбой S3-хранилища)
- Утрата транзакционных данных платежных операций
- Остановка операционной деятельности
- Экономические убытки от невозможности обработки данных

### 3. Модификация информации
**Описание**: Несанкционированное изменение данных, приводящее к их недостоверности.

**Потенциальный ущерб**:
- Изменение сведений о правообладателях (системы CRM, tenant-core)
- Искажение каталога недвижимости (приложение client-mart)
- Сбои в работе интеграционных сервисов (СМЭВ, процессинг платежей)
- Правовые споры из-за неверных данных
- Экономический ущерб от некорректных транзакций

### 4. Снижение качества информации
**Описание**: Накопление неточностей и дублирований в массивах данных.

**Потенциальный ущерб**:
- Множественные записи об одних клиентах в CRM
- Неактуальные характеристики объектов (метраж, правовой статус)
- Искаженная аналитика на основе хранилища DWH
- Ошибочные управленческие решения
- Снижение лояльности клиентов из-за ошибок в документации

### 5. Потеря актуальности информации
**Описание**: Хранение и использование устаревших данных.

**Потенциальный ущерб**:
- Неактуальные списки объектов (реализованные, но присутствующие в системе)
- Устаревшие прогнозные модели в DWH
- Избыточное хранение неиспользуемых данных (архивные логи)
- Расходы на поддержку ненужной инфраструктуры
- Неверные прогнозы реализации

## Визуализация рисков
Детальная оценка каждой угрозы представлена на прилагаемой диаграмме с цветовой индикацией уровней критичности.
