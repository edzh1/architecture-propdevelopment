# Приоритетные области аудита информационной безопасности

- **Вопрос 1**: Внедрение двухфакторной аутентификации для критических систем

- **Вопрос 3**: Регулярный аудит привилегированных аккаунтов
- **Вопрос 4**: Применение принципа наименьших привилегий
- **Вопрос 5**: Автоматизация блокировки учетных записей уволенных сотрудников

- **Вопрос 10**: Ограничения на внешний доступ к системам
